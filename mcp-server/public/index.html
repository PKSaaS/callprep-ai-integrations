CallPrep MCP Server

Remote MCP server for CallPrep — B2B lead research for sales follow-up and call prep.

Endpoint: POST /mcp (Streamable HTTP, stateless)

Tools: research_lead (submit research on a lead's email), get_research_result (poll for the result).

Connect

Claude Code, with your own CallPrep API key:

claude mcp add --transport http callprep https://THIS-HOST/mcp \
  --header "Authorization: Bearer cp_live_YOUR_KEY"

claude.ai / Claude Desktop: Settings → Connectors → Add custom connector → paste https://THIS-HOST/mcp.

Get a free API key at callprep.app → API Keys.
